# 工作记录

记录**干到哪儿了、接下来干什么**。一页纸，不追求详细。

- **[NOW.md](NOW.md)** —— 唯一需要每次读的：上次做到哪、接下来干什么、当前状态、别忘的坑。
- `YYYY-MM-DD.md` —— 单次对话的经过，**需要时才写**。细节留在提交信息里，这里只写下次可能用得上的。

## 和 `design-log/` 的分工

| | `work-log/`（这里） | `design-log/` |
|---|---|---|
| 回答 | 干到哪儿了、接下来干什么 | 为什么这么做、放弃了什么 |
| 写法 | 一页纸，**频繁改写** | 按主题累积，**基本不改** |
| 生命周期 | 过期就更新 | 废弃了也保留 |

冲突时以 `design-log/` 为准——它记的是决策，这里记的是进度。

## 约定

**开工前**：读 `NOW.md`。如果这次要做的事在"接下来干什么"里，直接照做；不在的话再看 `design-log/INDEX.md` 找相关设计。

**收工前**：

1. 更新 `NOW.md`：改"上次做到哪"和"接下来干什么"，勾掉做完的
2. 有设计决策 → 写 `design-log/`
3. 有值得下次知道的经过 → 写 `work-log/YYYY-MM-DD.md`；没有就不写

**不写什么**：不抄代码、不贴 diff、不复述提交信息。提交信息里已经有的，这里不重复。
