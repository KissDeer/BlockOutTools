# 削掉模块层，把两张画布嵌合成一张

**日期**：2026-09-17
**状态**：提案（分两步；第一步未开始）
**取代**：[主流程收敛为两个工作面](2026-09-16-主流程收敛为两个工作面.md) 的"两个工作面"形态

---

## 背景

09-16 那轮把主流程收敛成 `逻辑拓扑 ⇄ 拼接搭建` 两个工作面，用左上角两个按钮切换。用户走了一遍后提出反对，四条意见：

> 1. 逻辑拓扑图里已经包含了很多信息，那我不用去切这个模块，切模块有点多此一举。
> 2. 我搭建这个模块的时候，你也不给我显示里面到底有几个相关的逻辑东西，重点是我要互相连接。没意义的事情就不做了，**模块不需要了**，就按照逻辑拓扑图的节点进去做。
> 3. 逻辑拓扑图里面可以嵌套逻辑拓扑图……但怎么切换到之前模块里那种拼接搭建的内容？
> 4. 现在是左上角两个按钮切换，但问题在于它是**整个界面的切换**——切过去以后你不知道从属于哪个逻辑节点，也不知道在拼哪个，**更没办法整体观察所有逻辑节点**。

第 4 条是真正的痛点，而且**和模块无关**：换成任何两个顶层页签都会有同样的问题。第 1、2 条是另一个问题：模块这层中间商没有带来价值。

## 决定

### 一、削掉模块层

逻辑节点**自己就是可搭建单元**：

```
逻辑节点
  ├─ 内部是几何 → 叶子：直接在里面搭
  └─ 内部是逻辑 → 复合：里面又是一张逻辑拓扑（可多级）
```

不再有 `拆解 → 分组 → 模块 → 构型` 这条链。几何直接挂节点。

**"模块"这个词在产品里消失**。原来的拆解页、构型页、"搭建"按钮、"放入整体"都随之取消。

### 二、一张画布，层级即导航

- **取消顶层两个页签**。进入节点 = 画布聚焦到那一层，面包屑随时退回。
- 任何时刻都能缩出来看全局；分不清"我在拼哪个"这个问题从根上消失。

### 三、节点内显示两层信息

每个节点内部同时显示：

1. **拼好的 2D 内容** —— 多层嵌套时显示**展平后的最终结果**（小房子 → 带大庭院的小房子 → …）。
2. **它的内部逻辑** —— 里面有几个东西、它们怎么连（小房子 ↔ 大庭院）。

### 四、参考图跟着层级走

| 当前层级 | 旁边显示 |
|---|---|
| 最外层 | 整张地图的逻辑拓扑图 + 氛围图 |
| 进入某节点 | 该节点内部的拓扑图 / 氛围图 / 三视图 |

## 考虑过的选项

### 旧分组（一个模块含多个区域）怎么落

| 选项 | 代价 |
|---|---|
| **每个区域各自成为单元** ✅ | 最彻底、模型最简。代价：原本同模块但彼此无连线的区域（Boss 房 + 中庭）变成两个独立单元，需要补一条连线或嵌一层 |
| 旧模块转成一层嵌套拓扑 | 旧项目结构不丢。代价：多一层包装，和"模块多余"自相矛盾 |
| 先不管旧数据 | 新项目走新模型，旧项目只读 |

选第一个。用户原话是"没意义的事情就不做了"，留一层兼容包装就是没意义的事情。

### 嵌套的内部逻辑能否被多个节点引用

**能复用**。这是 09-13 就确认过的"Scope 可当复用资产（同一个鬼屋用在两张地图里）"的延续。代价是必须保留环检测——已经实现了。

### 界面形态

| 选项 | 代价 |
|---|---|
| **单画布 + 焦点层级** ✅ | 进入节点 = 画布换焦点，面包屑退回。任何时候都能看全局 |
| 画布上就地展开/折叠节点 | 像文件夹树。节点一多画布会失控 |
| 上下分栏（上逻辑、下几何） | 屏幕空间被切两半，两边都看不清 |

### 落地节奏

**分两步**（用户确认）：

- **第一步**：一张嵌套画布 + 节点内显示内容 + 参考图跟层级。模块层暂时还在但不挡路，每阶段都能用、能验证。
- **第二步**：从领域层、UI、数据里删掉模块。

一次到位的代价是中间长期不可用、验证周期长；分两步的代价是会出现"一半新一半旧"的过渡状态。

## 放弃或推迟了什么

- **放弃"两个工作面"这个形态**（09-16 的决定被本轮修正）。数据模型和领域能力继续用，只是操作入口合并。
- **放弃模块作为复用单位**。复用改由"嵌套内部逻辑"承担，粒度更自然（复用的是一个空间，不是一个打包）。
- **放弃"放入整体"这个动作**。节点本来就在地图里，不存在"放"。
- 第二步之前，拆解/构型相关的旧能力仍留在代码里，但不作为主路径。

## 已知边界与风险

- **"整体观察"到底做到什么程度没有定**。缩出去看上一层算不算？还是要在同一屏里看到所有层级的缩略？这决定了画布的实现复杂度，需要在第一步里用真实数据确认。
- 节点内同时显示几何 + 内部逻辑，节点尺寸小的时侯会糊成一片。缩略图的信息密度需要实测调。
- 旧的 `ModuleDefinition` / 实例 / 连接数据在第二步要迁移或冻结，迁移规则未定。
- 3D 预览与 UE 导出目前吃的是"实例 + 模块定义"，节点化之后要改成吃"展平后的节点几何"。
