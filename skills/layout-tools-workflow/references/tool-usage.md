# V2 操作

启动：双击根目录 `Start-BlockOutTools-V2.cmd`，打开 http://127.0.0.1:4174/ 。首次在 `app-v2` 安装依赖。启动窗口可见，不使用隐藏执行或策略绕过。

默认进入“构想工作台”：逻辑拓扑 → 输入上下文 → 识别 → 拆解 → 构型。识别采用 agent 读图、提交候选和人工确认；拆解与构型也可同步拓扑、拉取提案后套用。拓扑同步包含根与全部子作用域、各层规则和来源引用，并用 activeScope 标明当前层及其指纹；agent 应使用 activeScope 中的输入、拓扑与划分指纹生成当前层提案。原图仍通过输入同步接口读取。

模块可展开为子作用域；通过“进入”和面包屑逐层编辑。子作用域可以复用，收起只解除引用。根层交付检查引用到的子层，未引用的草稿不参与交付。项目导入仍会检查池中所有层的引用是否合法。

构型套用后点“生成组装”，再切到“拼接与转化”。套用更新对应模块积木，同一来源的体块和端口保留身份，移除端口时解除其关联连线，整次操作可撤销。人工修改与新提案的逐项冲突合并尚未实现。跨层链路仍需约定边界入口，未接通项显示在生成结果中。

无限画布直接新建/复用模块。缩略图和箭头按模块内部真实 XY/角度显示；拖动画布卡片仅用于排版。双击进入内部，Box、门洞、直梯和出入口复用统一选择/变换/删除。返回后拖动或依次点两个空闲端口连接。

选择连接可改类型、删连接、填写向前/横向/高差。高差是终点相对起点，正高负低；单向只表示通行语义。类型改变保留自定义距离，可按钮恢复默认。实例右栏“设为组装基准”固定该实例的定位依据。连线不生成实体楼梯。

双击连线增加折点，选中连线后拖动折点调整，双击折点删除。折点只影响二维连线，不改变三维距离。

内部 Box 可选用途与高度基准。行走表面 Z 模式厚度向下，切换模式保持原几何位置。直梯可填两端落脚点和平台表面高度，计算并应用；空间不足时修改落脚点或做折返梯，不自动拉伸。

W/E/R、Delete、Ctrl+C/V/D、Ctrl+Z/Shift+Z 复用编辑语义；输入框、对话窗口和预览时屏蔽画布误操作。自由移动或 1/10/50/100cm 吸附，适应模块依据实际边界计算。

“规范检查”打开项目尺度设置和诊断，点击问题选中相关积木。支撑检查只用于明确标注楼板/落脚平台的模块。三维默认收起且手动刷新，可隔离模块、显示端口方向、输入剖切高度；端口闭合不能代表全路线可走。

## 本地文件

首次 Ctrl+S 或“保存到磁盘”，随后自动保存；默认 `data/projects-v2` 下按项目分目录，清单与模块分文件。顶栏“本地项目库”显示实际路径并选择打开文件。换项目时保留恢复草稿；“导出 V2 项目”仍下载整文件备份。

“另存为独立项目”创建新项目身份，保留模块与积木内容；普通改名不会改变身份或另开文件。最后磁盘合并基线保存在 IndexedDB，浏览器轻量草稿仍在 localStorage。

服务重启/刷新后用磁盘与草稿恢复。发生外部修改停止自动保存，点“读取磁盘并合并”；不同字段自动合并，同字段列出冲突，请先导出草稿再通过 Git 处理。旧模块内容保留在模块文件夹中供恢复。

## 图纸

进入模块后点击“图纸底图”：导入 PNG/JPG/WebP，填已知长度的像素与厘米值进行校准，调原点、旋转、透明度，记录图例。每个拆分区域独立校准；展开图的纸上距离不是实体间距。

导出解释模板，按 `docs/rebuild/DIAGRAM_INPUT.md` 填轮廓、楼梯上下落脚点、端口等，再读取并接受当前模块。接受可撤销，未出现的旧对象不会静默删除。图像本身不自动转建筑，SVG/DXF/PDF 目前先转底图，透视图需已知尺度/多视图依据。

命令行候选生成：

`node scripts/generate-diagram-project.mjs 基础项目.blockout.json 解释.json 新候选.blockout.json`

不覆盖输入或现有输出，不写 UE。历史洛斯里克脚本中楼梯空间不足会报错，不能把旧脚本或样例当成精确可走性证明。

UE 面板仅本地 dry-run；CLOSED/SLOPED 形态未核实，当前以 BOX 近似并给提示。实际 UE Apply 与回读需明确授权。
