# V2 维护

## 架构与身份

`app-v2/src/domain/` 保持纯数据与命令，不依赖 React、Konva、Three.js、DOM 或 UE。Store 管理命令历史、选择和草稿。项目深层修改经领域命令提交。

预览与 UE 使用 `resolveAssembly()` 的同一实例结果；图画布位置不参与实体定位。显式组装基准优先，否则使用实例顺序；边遍历按稳定 ID 排序。连接距离优先读取 `spacing`，默认值只是未定制时的回退；闭环残差必须显示。

出入口复用普通积木操作。端口占用是实例 ID + Port ID，复用定义不会占用另一个实例的对应端口。类型改变只影响拼装，不产生连接器实体。

UE 同步身份是 projectId / instanceId / blockId，改名、移动和排序不能重建身份。项目导入校验重复 ID、引用与端口占用。旧项目缺少角色与高度基准时保持底面语义，不自动抬高/降低旧几何。

`spatial.ts` 集中解释 Box 底面、行走表面与直梯落脚点。二维旋转映射到 Three 的 X/Y/-Z 时使用正 Y 轴旋转；UE 计划仍沿用负 Yaw。不要混淆两个坐标转换。CLOSED/SLOPED 的预览仅近似并告警；没有插件回读不得宣称一致。

移动只改位置，旋转只改角度，缩放反写关键尺寸。标签不进入 Konva 变换包围盒。预览显示控制只读取最后手动刷新的快照。

## 文件系统

Vite 的 `server/project-library.ts` 提供本机项目 API，开发与 preview 服务均加载。默认数据目录为仓库 `data/projects-v2`，个人/测试目录使用 `BLOCKOUT_V2_DATA_DIR`。

模块是按内容摘要命名的独立文件；清单原子替换后才切换版本，旧模块文件保留。清单和实际引用模块共同形成保存版本指纹；并发写串行，旧指纹拒绝覆盖。所有项目/模块路径受校验，不跟随链接。只绑定本机。

`project-merge.ts` 按稳定对象身份做三方字段合并，向量/折线视为整体字段。同字段、删除对修改、无效引用不得静默覆盖。浏览器草稿与最后磁盘基线用于恢复；内容比较忽略 JSON 对象字段顺序。

不要把 `data/levels` 或 `data/projects-v2` 清理掉。浏览器回归在临时库与独立端口运行，避免改写用户页面。

## 图纸输入

参考 `docs/rebuild/DIAGRAM_INPUT.md`。每模块保存原图、校准、图例和解释文件。特征 ID 不由总体数组序号决定；再生成按 ID 更新，缺失项保留并报告，不猜测删除。

正交多边形楼板带洞精确拆为 Box；非正交形状拒绝近似冒充精确。墙段可任意旋转并短段拼接；楼梯由两端约束生成。解释文件接受是单次可撤销命令，接受前检查模块修订未变化。

## 检查与交付

在 `app-v2/` 运行 `npm test`、`npm run check`、`npm run build`、`npm run verify:level`。运行被修改的生成脚本；拒绝非法输入也是需要记录的行为。前端修改另验真实桌面浏览器、控制台、操作与非空截图。静态测试不证明 UE 碰撞/全路径可走。

只在用户要求时提交或推送。完整工具交付包含当前共享示例，但不纳入无关机制表、Excel 临时文件、密钥和浏览器测试产物。同步本 Skill 并验证。
