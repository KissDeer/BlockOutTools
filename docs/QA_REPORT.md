## 参考版既有问题

1. 参考版与本地版在撤销一次绘制后，“重做”按钮都会保持禁用，`Ctrl+Y` 也无法恢复形状。该问题属于 `v0.0.2` 原始构建，不是本地宿主引入的差异。
2. 768px 宽视口下，顶部“缩放: 100%”会被压缩成多行竖向文字。页面没有整体横向溢出，但顶部栏可读性下降。
3. 3D 模式会输出 Three.js 的 `THREE.Clock` 弃用警告，不影响当前渲染。
4. AI 文本/图片生成、远程模型调用和真实 API Key 未测试；这些能力依赖用户自己的外部服务配置。
