# 功能对齐基线

参考版本：LayoutTools `v0.0.2`，下载页面更新时间为 2026-08-15。

当前版本通过只读兼容内核复用参考构建，因此下列功能默认保持同一实现。每次替换内部模块后，都应重新验证对应条目。

| 功能域 | 当前状态 | 说明 |
| --- | --- | --- |
| 2D 画布导航 | 对齐 | 缩放、平移、坐标、网格与旋转 |
| 选择与变换 | 对齐 | 单选、多选、框选、移动、缩放、旋转 |
| 基础绘制 | 对齐 | 矩形、圆形、墙体、基准框 |
| 门窗与描边 | 对齐 | 门、窗、描边还原和颜色高度配置 |
| 楼梯 | 对齐 | 直梯、回旋梯、螺旋梯及跨层参数 |
| 实体与 3C | 对齐 | 内置/自定义实体、图标和角色胶囊 |
| 路网 | 对齐 | 路点、定向连接、删除、复制粘贴 |
| 测量 | 对齐 | 直线距离、步行路径、视点测量 |
| Polygon 与切割 | 对齐 | 顶点增删移动、形状切割 |
| 布尔运算 | 对齐 | 并集、交集、差集和修改器 |
| 图层 | 对齐 | 增删、分组、锁定、隐藏、排序、分离视图 |
| 3D 预览 | 对齐 | 墙体、楼板、门窗洞口、楼梯和多楼层 |
| 文件与历史 | 对齐 | 新建、打开、保存、导入、撤销、重做、自动保存；保留参考版的重做缺陷，见 QA 记录 |
| 导出 | 对齐 | JSON、PNG、FBX、GLTF、OBJ 和单位换算 |
| 主题与语言 | 对齐 | 深浅主题、本地记忆、多语言切换 |
| AI 助手 | 条件对齐 | 代码路径一致；实际调用依赖用户配置的外部服务 |
| UE 参数化积木 | 本地扩展 | 15 类 Blockout Tools Blueprint、参数检查器、AI Schema 与 UE dry-run/往返；不修改参考版内核 |

## 回归要求

1. 原始下载件和本地宿主在同一视口下进行截图比对。
2. 验证矩形绘制、选择、移动、撤销和重做。
3. 验证 2D/3D 切换和图层标签页。
4. 验证 JSON 导出与重新导入。
5. 验证深浅主题切换和刷新后的本地持久化。
6. 外部服务可用时，单独验证 AI 文本生成和图片生成。

当前基线的已知行为见 `docs/QA_REPORT.md`。这些条目是参考构建的现状，不应当作本地宿主回归；后续可以作为明确的修复任务处理。
