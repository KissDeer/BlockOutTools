# 从灵感意象到概念建筑

## 结论

这类工具的核心不是把参考物直接做成建筑，而是先提取意象的可设计特征，再把特征翻译成体量、结构、空间、立面、材料、光线和场景关系。一个稳定的工作流应当把“像什么”改写成“建筑如何组织”。

## 从网页中可以确认的内容

页面提供以下输入：

1. 上传抽象设计元素、符号或意象图片。
2. 选择设计领域：建筑、立面、家居、门头、展厅、景观、大门或舞台。
3. 选择画面比例：`1:1`、`4:3`、`3:4` 或 `16:9`。
4. 选填“参考元素或要生成的内容”的补充描述。
5. 选择模型版本和输出分辨率后生成图片。

前端代码表明，选择预设领域时，最终请求的文本由“该领域的后台描述 + 用户补充描述”拼接而成，同时把上传图片作为图生图参考。页面没有公开后台领域描述的明文内容，因此不能从这份网页快照还原它的原始完整提示词。

以下流程和模板是依据页面交互、请求结构以及八类示例图重建的通用方法，不是网站原始系统提示词的逐字提取。

## 核心转译流程

### 1. 先定义任务，而不是先描述造型

至少确定：设计对象、使用者、场地、规模、主要功能、需要表现的视角。缺少信息时可采用明确标注的合理假设，不要用空泛形容词填补。

### 2. 把意象拆成设计基因

从参考图中提取五类信息：

| 维度 | 观察问题 | 建筑用途 |
| --- | --- | --- |
| 几何 | 轮廓、曲率、分叉、重复、比例是什么 | 体量、屋顶、开口、单元 |
| 组织 | 聚合、层叠、放射、编织或渐变如何发生 | 平面、结构、模块、空间序列 |
| 动势 | 生长、旋转、流动、悬浮或张力指向哪里 | 流线、入口、轴线、视线 |
| 物性 | 透明、粗糙、轻盈、厚重、柔软或坚硬 | 材料、构造、表皮深度 |
| 氛围 | 光色、季节、文化联想和情绪是什么 | 光线、色彩、场景叙事 |

选出一个“主基因”和不超过两个“辅基因”。主基因控制空间或体量，辅基因只控制局部。这样能避免把参考图的所有特征堆在同一个方案里。

### 3. 建立意象到建筑的映射

不要只写“建筑像莲花、竹子或海浪”。应写成可执行的关系：

- 花瓣的层叠关系 -> 多层遮阳顶棚与递进式公共空间。
- 竹节的分段节奏 -> 竖向体量分节、设备层和空中连桥。
- 水流的连续曲率 -> 主流线、屋顶排水方向和连续表皮。
- 编织纹理 -> 可重复的结构网格、遮阳密度和透光梯度。
- 山谷的夹合关系 -> 两侧实体体量围合中央共享空间。

每条映射都要说明它影响的是体量、结构、空间、立面、材料、光线还是景观，避免同一个意象同时无约束地控制所有层面。

### 4. 同时生成三条不同路线

1. **形态抽象**：保留轮廓、比例和节奏，但去掉具象细节。
2. **结构转译**：把意象的生长、编织、分叉或受力逻辑转成结构和模块。
3. **氛围转译**：弱化外形相似度，保留光影、材质、空间情绪和行为体验。

三条路线应共享同一功能和场地约束，差异来自转译策略，而不是随机更换风格。

### 5. 用建筑约束收敛

检查入口是否可识别、功能分区是否成立、流线是否连续、尺度是否可信、结构是否有基本逻辑、表皮能否分段建造、材料是否适合环境。概念图不等于施工方案，但不能以“概念性”为理由忽略基本空间逻辑。

## 通用提示词公式

```text
设计任务：为【场地/使用者】设计一座【建筑类型、规模和主要功能】。

灵感来源：参考图中的【主意象】。不要复制物体外形，也不要把建筑做成巨型雕塑；提取其【几何特征】、【组织规律】、【动势】、【物性】和【氛围】。

建筑转译：
- 将【特征 A】转译为【体量/空间/结构】；
- 将【特征 B】转译为【立面/开口/遮阳】；
- 将【特征 C】转译为【材料/光线/景观】。

空间与功能：包含【主要功能】，入口位于【位置】，形成【公共到私密或室外到室内的空间序列】，人流与后勤流线【关系】。

构造与材料：采用【结构逻辑】和【主材料】，表皮具有【模块、厚度、接缝或透光方式】，造型应能分段建造并保持可信尺度。

画面表达：【视角】，【时间与天气】，【画幅比例】，展示完整建筑、入口、场地关系和人物尺度。建筑概念设计图，高细节，清晰结构层次，材质真实。

避免：直接复制参考物轮廓、符号贴花、无功能雕塑、随机曲面、悬空体量、不可识别入口、尺度混乱、结构逻辑缺失、过度未来感、文字、水印。
```

## 适合图生图的短提示词

```text
把上传图仅作为意象和设计规律的参考，不做外形复刻。提取其中的【主几何】、【组织节奏】与【材质/光影特征】，将其分别转译为【体量与空间】、【结构或立面系统】和【场景氛围】。设计一座位于【场地】的【建筑类型】，满足【核心功能】，入口清晰、流线可信、人物尺度准确、构造可分段实现。采用【视角】与【画幅】，完整展示建筑和场地关系。避免巨型物体化、纯雕塑化和无结构的自由曲面。
```

## 方案评价标准

每项按 1 至 5 分评价：

- 意象识别：不看说明也能感受到来源，但不是外形照抄。
- 建筑转译：每个重要形式都有空间、结构或环境理由。
- 功能可信：入口、尺度、流线和主要功能可读。
- 系统一致：体量、立面、材料和景观使用同一组设计规则。
- 差异价值：方案之间是策略差异，而不是表面风格变化。
- 可发展性：概念能继续深化为平面、剖面、结构和构造。
