# 功能需求

状态：`已确认需求 · 2026-09-16 同步拓扑驱动搭建 A+B`

每条 P0 需求都必须有自动测试或浏览器验收证据。

本文同时保留长期需求；P0 不表示已全部实现。当前工作流以 FR-13 至 FR-15 和 [已确认方案](WORKFLOW_UX_PROPOSAL.md) 为准。UE Apply/回读、完整通用 AI 命令和整体自动对接尚不属于本次交付。

## FR-01 项目与文件（P0）

- 项目由一个清单文件和多个独立模块文件组成。
- 新建、打开、另存和最近项目都使用明确的本地文件位置。
- 编辑后自动保存可恢复草稿；正式文件写入必须原子化，避免中断后产生半个 JSON。
- 页面重开和服务重启后恢复最后项目和最后视图。
- 未保存状态、保存中、已保存和保存失败必须清晰可见。
- 旧 LayoutTools JSON 只能通过“导入旧项目”进入，不直接成为运行时模型。

验收：两个模块分别改动后，只改变对应模块文件；进程在保存中断时仍能恢复上一个有效版本。

## FR-02 无限画布（P0）

- 启动后进入逻辑拓扑画布；拼接搭建内的整体关系图使用本节的实例交互。
- 可新建、选择、移动、复制、粘贴、复用和删除模块实例。
- 模块卡片公布名称、实例名称、层高摘要、内部积木俯视缩略形态、真实相对位置的出入口和未保存/错误状态。
- 支持平移、缩放、框选、多选、适应全部和关系图折线编辑。
- 无限画布左侧不显示模块内部积木工具栏。
- 模块位置只表示关系图排版；实际组装 Transform 单独存储。

验收：两个内部形态不同的模块在无限画布上可直接区分；端口箭头与内部 XY 和旋转对应；移动关系图节点不会改变 3D 或 UE Transform；删除实例会清理其连接但保留模块定义。

## FR-03 模块定义与复用（P0）

- 模块是独立可移动、可复用的结构资产。
- 一个定义可拥有多个实例；内部元素只存一份。
- 复制实例产生新实例 ID，但继续引用同一定义。
- 复制模块定义产生新的定义与元素身份。
- 删除定义是显式高风险操作，并列出受影响实例。
- 模块可以独立导出、导入和三方合并。

验收：编辑定义后所有实例更新；重复实例导入 UE 时各自生成独立 Actor，且同步键互不冲突。

## FR-04 模块内部编辑（P0）

- 从逻辑拓扑点击“搭建模块”，或从整体双击实例/点击“编辑内部”，进入同一二维内部编辑器；无实例也能编辑定义。
- 空模块按需建立稳定定义，不要求先生成构型；已有几何直接打开，不重建、不重置实例。
- 返回保留进入来源，撤销内部修改保持当前模块编辑上下文，另有显式“查看整体”和“放入整体”。
- 支持单选、多选、框选、移动、旋转、缩放、复制、粘贴、删除、成组、锁定、隔离、对齐和分布。
- `W/E/R`切换移动、旋转和缩放；快捷键可配置为其他单键。
- 统一使用画布轴，不提供世界/局部轴切换。
- 支持网格吸附、顶点吸附和贴边；吸附可临时关闭。
- 位置、旋转和几何关键参数可数值输入。
- 撤销/重做必须覆盖所有编辑命令、属性修改、AI 命令和导入合并。

验收：连续执行 20 个混合操作后逐步撤销到初始状态，再完整重做，数据和画面一致。

## FR-05 积木目录与参数（P0）

- P0 以 Blockout Tools 插件面板的参数化 Blueprint 类型为可部署积木目录。
- Schema 定义类型、关键参数、默认值、范围、单位、二维投影、3D 预览和 UE 属性名。
- 参数编辑与画布控制柄必须双向同步。
- Box 的日常控制集中在 Transform、`BoxSize`、`blockout_material_color`和`blockout_material_top_color`；其他参数保持插件默认，除非类型需求明确暴露。
- 原网页对象通过 `LegacyShape` 导入兼容层保留；默认不出现在新建积木目录，且不保证 UE 可部署。
- 可增加纯标注对象，但必须显著区分“仅设计图可见”和“将导入 UE”。

验收：每种可部署积木可从 Schema 建立、保存、重开、3D 预览、AI 创建并完成 UE 往返。

## FR-06 出入口与连接（P0）

- 出入口使用与普通积木相同的放置、选择、变换、复制、删除和属性编辑机制。
- 出入口以箭头显示正方向，保存稳定 ID、名称、位置、旋转和局部 Z。
- 出入口不区分进入和退出；每个实例端口默认最多连接一次。
- 模块外部可连接普通门、单向门、楼梯、螺旋楼梯、普通电梯、单向电梯、普通路、单向下落路。
- 连线支持折点、不同线型和方向标识；不提供专门的分叉点对象。
- 连接首先表达拓扑和语义，P0 不自动生成连接器实体几何。
- 3D 与 UE 输出按端口位置、相向方向及连接类型偏移求解实例 Transform；每个连通分支以第一条连接的源实例为锚点，闭环残差必须明确报告。

验收：旋转内部出入口后，外部箭头同步；连接到错误朝向或已占用端口时给出明确错误；连接模块在 3D 与 UE dry-run 中端口相向并满足类型偏移。

## FR-07 3D 预览（P0）

- 预览是右侧可收起窗口，默认收起。
- 展开时占用足够主工作区，不把三维场景挤在窄栏中。
- 只有用户点击刷新时重建场景；普通编辑只标记“需要刷新”。
- 预览读取与 UE 转换相同的规范化积木几何和模块 Transform。
- 支持轨道旋转、平移、缩放、聚焦选择、重置视图和平面/层高展开。
- Stairs、Ramp、Doorway 等参数化类型必须按 Schema 重建，不能退化为占位 Box。

验收：相同项目的 3D 包围盒、层高和朝向与 UE dry-run 计划在容差内一致。

## FR-08 白盒规范（P0）

- 项目设置中有独立“白盒规范”页面，不与单个积木属性混杂。
- 可配置角色胶囊、视点、跨步、跳跃、门洞、通道、净空、楼梯、落脚区和坡道限制。
- 规范可关闭；可单独选择是否阻止 UE Apply。
- 错误列表可定位到模块实例和内部积木。
- 只有被 Schema 明确认识的几何参与硬校验，未知对象不得产生伪精确结果。

验收：同一错误在项目检查、3D 检查提示和 UE dry-run 中返回相同规则编号与对象 ID。

## FR-09 AI 编辑（P0）

当前 A+B 实现是 FR-15 的模块局部草案替换事务；下面的通用命令全集仍是后续目标，不能据此认为已有自动模型调用或任意对象 patch 接口。

- AI 使用和人工编辑相同的积木目录、参数规则和命令历史。
- 模型不能直接操作网页控件；只能提交结构化领域命令。
- 最小命令集包括项目读取、模块建立、积木增删改、端口建立、实例建立、端口连接、规范检查和差异预览。
- AI 修改先显示影响范围和验证结果，用户接受后进入正式历史。
- AI 修改现有内容时必须引用稳定 ID；不得通过整份重建改变无关 ID。
- 模型提供方和 Key 是可选本地配置，不进入项目文件、日志或提示正文。

验收：相同命令批次重复执行不会重复创建对象；非法类型、非法参数和越权删除被拒绝且不产生部分修改。

## FR-10 UE 桥接（P0）

- UE 连接、身份检查、dry-run、Apply 和回读是分离步骤。
- dry-run 返回 create、update、unchanged、retain、delete 和 conflict。
- 默认只操作本工具拥有且属于当前项目的 Actor。
- Apply 必须核对项目名、完整 `.uproject`、目标地图和未过期计划。
- 删除默认关闭；开启后必须重新 dry-run。
- Apply 失败要回报具体 Actor，并清理新建半成品；不得自动保存地图。
- UE 回读可以生成差异或导入项目，不得静默覆盖网页未保存改动。

验收：同一项目连续 Apply 两次，第二次全部为 unchanged；网页元素 ID 改名不改变 Actor 身份；复制实例只新增该实例的 Actor。

## FR-11 图片转关卡（P1）

- 从图片识别拓扑是辅助导入工具，不是一级页签或手工搭建前置条件；模块初始化也可引用图片，但只返回局部候选。
- 先输出可审阅的观察结果：区域、楼层、高差、墙、平台、内部连接和跨模块连接。
- 再把观察结果转换为候选模块、积木和连接命令。
- 用户可以逐模块接受、修改或拒绝；不得直接覆盖当前项目。
- 图上路线、文字和标注默认解释为语义，不自动生成实体墙。

验收：生成结果可以固定为确定性命令文件，并在空项目中重复得到相同结构。

## FR-12 模块协作与冲突（P1）

- Git 管理正式项目和模块文件；工具负责结构化三方合并。
- 冲突最少显示对象、字段、base、current 和 incoming。
- 支持逐冲突选择，不只支持整包采用一侧。
- 合并完成后重新运行 Schema、端口占用、连接和白盒规范检查。

验收：两人修改同一模块不同积木自动合并；修改同一参数产生一个可定位冲突，不丢失任何一侧值。

## FR-13 拓扑持续驱动搭建（P0，当前 A）

- 顶层只有逻辑拓扑与拼接搭建；模块分组并入拓扑，独立拆解、构型主入口撤下。
- 框选成组、拖入/拖出与标题整组移动沿用节点、链路和模块 ID，松手后一次提交；图上四向连接点继续可用。
- 模块内部显示成员区域、备注、内部通路和跨模块接口需求，语义来自原拓扑，不复制第二套关系。
- 图上排版、模块局部几何与整体实例坐标分开。只移动排版不改变几何，也不使局部草案失效。
- “放入整体”仅为所选定义和路径补充或定位实例，保留已有实例位置与旋转；共享作用域有多个路径时显式选择。
- 跨模块链路变化只更新需求，不自动开洞、替换端口或重生成几何。自动几何对接及完整回改属于 C。

验收：无范围图、无整体坐标时可从分组进入空模块；已有定义直接打开；查看整体不新增或重置实例；单模块放置不改其他模块；撤销不意外退出编辑器。

## FR-14 常驻项目与模块上下文（P0，当前 A）

- 项目目标与关键约束摘要常驻，完整文字可展开；模块目的、目标、结构图和氛围图在内部编辑时同时可见。
- 选择积木时模块参考栏不被属性检查器替换；切换模块按稳定定义 ID 解析资料。
- 首版支持项目/模块两级资料，一份资料可关联多个模块，不复制图片正文；实例共享定义级资料。
- 旧输入保留在原作用域，根输入作为项目资料，当前模块继承所属作用域输入和模块底图，不凭名称猜配。
- 同一解析结果供页面和 AI 请求使用，包含区域/链路备注及锁钥语义；缺原图明确提醒。
- 文字目标、氛围和硬约束都作为参考保留来源；首版不声称自动理解或验证任意自然语言约束。

验收：结构图、氛围图与目标可并列查看；多模块共享资料只存一份；切换、改名和保存重开不串用；无关模块专属资料变化不使当前请求失效。

## FR-15 模块局部初始化与确认（P0，当前 B）

- “快速体块起稿”是确定性模板，明确默认尺寸、未解读图片、局部间距与未定接口朝向。
- “AI 初始化参考”准备当前模块材料并经本地 agent 桥接返回候选；未自动调用模型时显示等待 agent，不显示假进度。
- 请求带项目/模块/请求身份、相关上下文指纹、几何基线和可读取图片；结果带局部位姿、来源区域/链路及假设。
- 同画布预览不写入；采用前检查目标、来源、几何、区域覆盖和跨模块端口，相关内容变更后拒绝旧草案。
- 已有内容显示新增/修改/移除及实际对接影响，明确确认后替换当前模块；取消零写入、采用一次撤销。
- 同语义来源保留已有体块和端口 ID；不得复用其他语义的 ID 劫持连接，不允许更改拓扑归属或锁钥规则。
- 采用不等于完成。可显式标记形态已确认；相关要求或几何改变后待核对；形态状态不等于空间对接或玩法验证。

验收：非法、其他项目/模块、过期或伪造来源草案被拒；草案采用与撤销保护原模块和无关实例；JSON 和分文件保存保留新增资料与确认字段。当前没有自动模型调用、隐式追加或局部几何自动合并。
