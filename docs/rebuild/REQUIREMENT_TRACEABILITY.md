## 2026-09-16 工作流修订追踪

| 用户反馈/决定 | 当前 A+B 处理 | 依据与边界 |
| --- | --- | --- |
| 模块拆解已在逻辑拓扑完成 | 分组并入拓扑，撤下拆解/构型主入口 | FR-13；保留旧数据和领域能力，不强制重做 |
| 后面应持续使用第一步数据 | 模块参考解析成员、内部链路、对外接口及备注 | `workflow-context.ts`；几何/玩法实现状态单独核对 |
| 上下文要总能看到 | 项目提醒常驻，模块资料与积木属性并列 | FR-14；项目/模块两级，区域/链路附件后续扩展 |
| 结构图、氛围图、设计目标一起看 | 模块左栏同时呈现，图片可放大固定 | 不以选中积木替换模块资料 |
| 形态生成内化到拼接 | 空模块直入，手工编辑或预览局部草案 | FR-15；无整体坐标/参考图也可手工制作 |
| AI 初始化参考 | 独立 agent 请求/返回，实际材料与双基线检查 | `module-draft-contract.ts` / `module-draft-bridge.ts`；不自动调用模型 |
| 旧角色生成是否 AI | 命名“快速体块起稿”，标明确定性默认尺寸 | 不声称已理解图片 |
| 保护已有模块和实例 | 明确替换、差异确认、一次撤销、同源 ID 保留 | 不自动覆盖手工内容；局部几何自动合并延期 |
| 放入整体无需全项目生成 | 仅当前模块显式补充/定位，复用路径显式选择 | `module-workflow.ts`；原 Transform 保留 |
| 自动整体对接与完整回改 | C 批次 | 本次仅沿用端口连接、实例属性和 3D，不宣称完成自动链路匹配 |
| 旧文件继续使用 | schemaVersion 2 可选字段扩展 | 新版读旧版；旧程序可能丢弃新增字段，不承诺反向保存兼容 |

回归入口：`module-draft.test.ts`、`server/module-draft-bridge.test.ts` 和模块流程/导航测试；浏览器与 UE 的执行证据另行记录，不由追踪表推定。

## 原重做版基础要求

以下不是旧网页功能，但对可靠重做是必要条件：

- Schema 版本和旧数据显式迁移。
- 项目、定义、实例、积木、端口、连接的稳定身份。
- 保存原子性、恢复草稿和明确脏状态。
- AI 命令事务和用户接受差异。
- 2D、3D、验证和 UE 的共享几何解释。
- UE 幂等 Apply、计划过期和失败半成品清理。
- 每条 P0 需求的自动测试与浏览器/UE 验收证据。
