# 历史需求追踪与取舍

状态：`Draft 1`

本表用于防止聊天中的旧要求再次无条件进入重做版。结论描述产品方向，不代表旧版本已经删除相应代码。

## 新增但必要的需求

以下不是旧网页功能，但对可靠重做是必要条件：

- Schema 版本和旧数据显式迁移。
- 项目、定义、实例、积木、端口、连接的稳定身份。
- 保存原子性、恢复草稿和明确脏状态。
- AI 命令事务和用户接受差异。
- 2D、3D、验证和 UE 的共享几何解释。
- UE 幂等 Apply、计划过期和失败半成品清理。
- 每条 P0 需求的自动测试与浏览器/UE 验收证据。
