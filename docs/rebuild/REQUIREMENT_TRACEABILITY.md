## 原重做版基础要求

以下不是旧网页功能，但对可靠重做是必要条件：

- Schema 版本和旧数据显式迁移。
- 项目、节点、积木、端口的稳定身份。
- 保存原子性、恢复草稿和明确脏状态。
- 2D、3D、验证和 UE 的共享几何解释。
- 每条 P0 需求的自动测试或浏览器验收证据。
