## 1. 信息架构（**已过时，见上方横幅**）

应用只有两个一级工作面：

1. **逻辑拓扑**：默认首页，在同一画布编辑区域、链路、锁钥和模块分组。
2. **拼接搭建**：内部包含整体关系图和当前模块编辑，通过来源返回、查看整体和模块入口切换。

项目目标与关键约束摘要在两工作面常驻，展开可编辑完整要求和项目资料。项目检查、3D 预览、UE 计划与文件操作是辅助操作；历史资料管理和图片识别收在拓扑辅助工具中。拆解和构型不再单列主步骤。

### 1.1 拓扑内组织模块

- 区域四向连接点拖线，主体选择/移动，空白框选，模块标题拖动整组；归属与位置只在松手后一次提交。
- 框选后组成模块；拖入/拖出调整归属，沿用原 ID。模块框不表示真实空间包围盒。
- 选中模块后点击“搭建模块”直接编辑；已有几何原样打开，空模块可从手工搭建或局部起稿开始。
- 子作用域继续下钻，模块资料绑定定义身份。缺图片、缺整体坐标、其他模块未完成都不阻止手工编辑。

### 1.2 连续编辑与返回

从拓扑进入时返回拓扑来源，从整体进入时返回原实例；撤销模块编辑不跳到整体。“查看整体”只切换视图，“放入整体”只补充/定位当前模块实例。多条复用路径须选择后放置，已有实例 Transform 保留。整体关系图拖动仅排版，厘米位置和旋转由实例属性控制；本轮不新增整体空间拖放工作面或自动逻辑对接。

## 2. 组装页面

### 2.1 布局

- 顶部：项目名、文件与保存状态、撤销/重做、两个工作面及常驻项目提醒。
- 左侧：模块库和筛选，可收起。
- 中央：无限画布。
- 右侧：选中模块/连接属性；3D 预览展开时替换右侧并扩展到主工作区。
- 底部状态：缩放、选择数量、错误/警告、3D 是否需要刷新。

旧版左侧绘图工具栏在此页面不显示。

### 2.2 模块节点

模块节点必须显示：实例名、定义名、层高、内部积木的俯视缩略形态、端口箭头、错误徽标和复用数量。缩略图按内部所有积木旋转后的二维包围盒自适应；Box、Doorway 和 Stairs 使用不同轮廓，端口箭头按内部真实 XY 相对位置和旋转叠加在缩略图中，并直接作为外部连线命中点。内部尺寸、位置或旋转变化后，所有复用实例的缩略图和端口位置同步更新。

双击节点进入内部。单击选中，拖动只改变关系图位置。实例真实 Transform 在属性面板或 3D 组装阶段编辑。

### 2.3 连接

选择连接类型后，依次点击起点端口、空白折点和终点端口。`Esc`取消，`Enter`结束当前路径。折点可拖动；双击线段增加折点；选中折点后 `Delete`删除折点；选中连线后 `Delete`删除连接。

连接线的颜色不能是唯一语义，必须同时使用线型、箭头和文字/图标。普通楼梯显示双向箭头；单向类型显示明确方向。

## 3. 模块内部页面

### 3.1 布局

- 顶部第一行：来源返回、模块名、查看整体、放入整体；项目目标与约束继续常驻。
- 编辑器内：AI 初始化参考、快速体块起稿、形态状态与确认，另保留当前积木编辑工具。
- 左侧：当前模块目的、目标、结构图、氛围图、内外连接要求及资料管理；图片可放大固定。积木目录独立保留，出入口使用同一套积木编辑机制。
- 中央：二维画布。
- 右侧：选中对象的 Transform 和关键参数。

不单独建立“出入口编辑栏目”。白盒规范属于项目检查，不塞进积木检查器。

模块参考栏默认显示，选择积木时继续保留；结构图与氛围图不要求在互斥页签间切换。添加资料明确归属项目或当前模块，可共享到其他定义；复用定义显示影响的实例数量。自然语言目标和氛围不显示伪精确的“校验通过”。

### 3.2 局部草案操作

“AI 初始化参考”展开补充意图与本次参考清单。点“准备本模块材料”后显示等待 agent，可复制任务/导出请求，再读取 agent 返回或导入 JSON；当前没有自动模型调用。缺原图提示与请求中的实际材料保持一致。

草案在当前模块画布预览，显示来源、假设、体块差异、受影响实例及移除对接数量。存在原几何时，“采用草案”先进入替换确认；明确确认才提交一次历史事务。“取消预览”恢复现状，不写项目。相关拓扑/资料或手工几何已改变时显示过期并禁止采用。

预览同时给出**采用代价**：试算套用之后的规范检查，列出会新增、会消除与原本就有的问题数量及条目；试算不通过时说明“采用会被拦下”。不能让人在采用之后才发现引入了硬错误。

同名资料分别标注“同名 1/2”等序号并给出提示：内容完全相同时说明保留任意一份即可，内容不同时说明无法判断当前版本、本次全部保留；两者都指明去哪个入口处理，不指错位置。资料管理与历史资料管理都提供删除，删除前说明影响面，可用撤销恢复。

“快速体块起稿”单独命名，清楚说明角色模板和默认尺度，不声称已参考图片。采用后继续手工编辑，可标记形态确认；后续相关要求或几何改变显示待核对。逻辑连通、形态确认和空间接口对接分别提示。

### 3.3 选择与变换

- 单击单选，`Shift+单击`增减选择，空白拖动框选。
- 拖动移动；控制柄缩放；旋转柄旋转。
- 多选时显示共同包围盒，移动和对齐使用同一画布轴。
- 锁定对象不能被普通框选；对象树或“解锁全部”可恢复。
- 数值输入只提交一个历史命令，连续输入不产生逐字符撤销记录。

### 3.4 积木放置

点击目录项进入连续放置；点击画布建立；`Esc`退出。放置前右侧显示模板关键参数。已放置对象选择后复用同一参数检查器。

出入口使用箭头外形，箭头方向对应局部正向。标注对象使用不同视觉语言，避免被误认为将导入 UE。

## 4. 3D 预览

- 默认收起，只显示“3D 预览”按钮和待刷新状态。
- 展开后主画布仍保留必要上下文，但预览获得主要空间。
- “刷新”是显式命令；刷新前显示上次结果和“已过期”。
- 选中 2D 或组装对象时，3D 中同步高亮；反向选择属于 P1。
- 预览错误不能只写控制台，必须显示类型、对象和建议动作。

## 5. 项目检查

规范页先显示配置，再显示错误与警告列表。问题条目包含规则编号、模块、对象、实际值、目标值和定位按钮。支持按规则、模块、严重级别筛选。

规范更改实时重新计算本地问题，但不自动触发 UE dry-run。

## 6. UE 同步

以下是后续完整桥接的交互目标；当前仅有本地 UE 计划 dry-run，不连接 UE、不执行 Apply 或回读。

面板按固定顺序展示：

1. Editor 与项目身份。
2. 当前网页项目和目标地图。
3. dry-run 设置，其中删除默认关闭。
4. 差异摘要和可展开 Actor 详情。
5. 冲突与规范阻断。
6. Apply 按钮和明确确认。

任何项目内容、目标地图或删除策略变化都会使计划过期并禁用 Apply。

## 7. 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `W` / `E` / `R` | 移动 / 旋转 / 缩放 |
| `V` | 按住时启用顶点吸附 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴 |
| `Ctrl+D` | 原位复制并偏移 |
| `Delete` / `Backspace` | 删除选择 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Ctrl+S` | 立即保存当前项目和脏模块 |
| `F` | 聚焦选择 |
| `G` | 网格吸附开关 |
| `Esc` | 退出工具或清空选择 |
| `Enter` | 完成连线或确认数值编辑 |

输入框获得焦点时，除 `Esc`、`Enter` 和保存外，不触发画布快捷键。快捷键冲突必须在设置中可见。

## 8. 可用性与桌面范围

- 支持常用桌面视口，最低目标为 1280x720；不维护手机端。
- 固定工具条不得覆盖画布选择框、3D 控件或属性面板。
- 长名称必须省略并提供完整悬浮提示。
- 颜色不能单独表达错误、方向、锁定或对象类型。
- 所有删除、Apply、覆盖和冲突解决操作必须能撤销或有明确确认与恢复路径。
