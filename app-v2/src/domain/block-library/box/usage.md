# Box 盒体

用于墙壁、地面、包边和落脚平台。这些是同一种盒体的用途，不需要增加新类型。

## 日常操作

1. 用位置 XYZ 和平面旋转摆放。
2. 用 BoxSize 的 X/Y/Z 修改长度、宽度和高度或厚度。旋转之后尺寸仍沿盒体自身轴。
3. 颜色只调整 blockout_material_color 和 blockout_material_top_color（顶面色，用户简称 top_color；数据使用完整字段名）。其他材质、碰撞和渲染属性保持插件默认。

尺寸三个分量必须大于零。网页尺寸输入框当前最小值为 1cm；文件 Schema 可接受更小的正数。颜色 RGBA 分量范围 0–1。

## 高度怎么填

XY 位于矩形中心。旧积木或未填 elevationReference 时按底面 Z 解释。

| 场景 | 用途 role | 高度基准 | 位置 Z 的含义 |
|---|---|---|---|
| 楼板 | floor | surface | 行走表面高度，厚度向下 |
| 楼梯落脚平台 | landing | surface | 落脚表面高度，厚度向下 |
| 墙壁 | wall | bottom | 墙底高度，向上长高 |
| 包边 | edging | bottom | 包边底高度 |

例如楼板表面 Z=300、厚度40，其实体从260到300；墙壁放在楼板上，底面 Z=300、高度300，其实体从300到600。

网页切换高度基准时会补偿位置，保持几何不动。AI 修改文件时也要补偿：bottom 切到 surface，位置 Z 加厚度；反向切换则减厚度。

role 与 elevationReference 是网页语义字段，不是向 UE 写入的插件参数。当前 dry-run 将表面位置换成底面位置；插件原点是否与此一致仍需 UE 实测。

## 摆放与检查

楼板应填满目标区域，必要时允许少量重叠，但不要用抬高薄片掩盖表面高差。短段墙壁便于改形和留开口，是建议而非强制规则。

需要支撑检查的地面设为 floor 或 landing；普通 solid 不会自动被当作已标注的行走表面。角色净空等按当前项目规范检查；表面相连不证明全路线可走。
