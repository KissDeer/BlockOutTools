# 直梯（待逐项确认）

当前 StairsSize 为宽度 X、进深 Y、高差 Z（cm），NumberOfSteps 是 1–1000 的整数。未旋转时沿局部 +Y 上升，位置 XY 在平面中心，位置 Z 为下落脚点高度。

优先给定下、上落脚点，使用网页的落脚点计算。每级高度=总高差/台阶数，踏步深度=总进深/台阶数；按项目 maxStairRise 和 minStairTread 检查。空间不足时报告并调整设计，不自动拉长楼梯。

上下落脚表面需实际支撑，检查落脚处和头顶净空。端口闭合不能替代这些检查。

StairsType 接受 BOX、CLOSED、SLOPED，但当前后两种仅用 BOX 近似预览并告警，不能据此验收。各形态与 UE 的一致性待实测。连接线类型选择“楼梯”不会创建该实体。
